# Sesler — lisans

## Kazanma sesi adayları (`WinCandidates/win-a.wav`, `win-b.wav`, `win-c.wav`)
- Üretim: `python Tools/make_win_sounds.py` — tamamen kodla sentezlendi (sinüs/çan kısmileri, gürültü patlamaları). Hiçbir örnek dosya, kayıt ya da üçüncü taraf kaynak kullanılmadı.
- Lisans: **CC0 1.0** (kamu malı). Ticari kullanım dahil serbest; atıf gerekmez.
- Seviye: oyundaki diğer seslere eşitlendi (RMS ≈ 0,10, tepe ≤ 0,5), 44,1 kHz mono 16-bit.
- Test sayfası: `docs/sounds/index.html` (yayında: https://zeydusht.github.io/reverse-solver-unity/sounds/).
