# UX kod denetimi

3 Kasım 2026. Denetim yalnızca mevcut çalışma kopyasındaki C# kaynakları okunarak yapıldı; Unity çalıştırılmadı, görsel/işitsel test yapılmadı. `GameRoot.cs`, `Ui/` ekranları, `Board/` girdi bağlantıları ve bunların `Draw/` ile `Core/Input/DragModel.cs` bağımlılıkları incelendi. `Library/`, `Logs/`, `Builds/` okunmadı. Aşağıdaki yollar `Assets/_Game/` köküne göredir; satırlar mevcut çalışma kopyasına aittir. “Doğrulanmadı”, koşullu riskin cihazda, belirli varlıklarla veya belirli kare sırasıyla yeniden üretilmediğini belirtir. Olumlu kontroller de tabloda yer alır; bunların önem derecesi düşüktür. Öneriler uygulanmadı.
